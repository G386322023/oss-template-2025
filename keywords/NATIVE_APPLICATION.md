# ネイティブアプリケーション

## 説明

ネイティブアプリケーションとは、スマートフォンやタブレットにインストールして使うアプリで、OS（例：iOS／Android）が提供する環境に最適化されているソフトウェアを指します。

ブラウザを通さずに端末に直接インストールするため、カメラ・GPS・センサーなどのハードウェア機能をフル活用でき、高速で安定した動作やオフライン利用も可能です。

一方で、異なるOSごとに別々に開発する必要があり、開発コストやメンテナンスの手間は増えがちです。
